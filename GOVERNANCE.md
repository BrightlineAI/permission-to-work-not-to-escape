# Project governance

Maintainer: Allister Lundberg.

The initial project is maintainer-led. Interfaces, evidence standards and security-sensitive changes should be reviewed before merging. This is not an industry standard or a certification scheme.

Decisions should favor explicit authority, compatibility with existing controls, reproducible evidence and useful permitted work. Record material design decisions and rejected alternatives in pull requests or short design notes.

As contributors join, maintainers can delegate ownership of adapters, policy schemas and evidence review. New maintainers and release rights should be documented here. No external endorsement is implied by citing a benchmark or vendor.
