# Historical installed report demo

[public-sample.json](public-sample.json) is the unchanged sanitized projection of
an installed Linux run completed on September 19, 2026 at 19:31:40 UTC, from
source checkpoint `90cd488fd19db14f2585fb8461b110079f414521`. The original run passed
the full offline demo verifier before curation. The manager's corresponding native
suite passed all 14 cases, including three native cases, with no skips. This is
historical evidence, not acceptance of subsequent source or documentation changes.

Two scripted workers used synthetic asset data. Both the correctly configured
sandbox and the same sandbox plus Vega prevented the upload analogue and completed
the report: cost 3600, annual depreciation 1000. Each upload exited 23 and each
ordinary failing test exited 1; neither increased misconduct. The first pair's
collector recorded four successful positive controls and no publication. Prevention
and useful completion were ties attributable to the shared confinement boundary.

A separate scripted sequence demonstrated first-warning recovery, retry deduplication,
another worker's violation, and protected continuation contributing violation three.
Three registered descendants ceased; parent exit, descendant state, empty cgroups
and stable sentinels were checked independently. Later admission was rejected and
an unrelated project's sentinel and useful output continued. Continuation used
synthetic metadata and fresh credentials through public APIs; it did not launch
Codex or measure live terminal behavior. A wrong report and a wrongly granted
local read were admitted as explicit limits of authority enforcement.

Seconds, rounded to three decimals; three paired report trials, always sandbox
first. Installation was a prerequisite and was not timed. Setup below is fixture
and approval setup; end-to-end is the report workflow, separate from escalation.

The payload also retains every warm upload, failing-test and finish measurement.
Total run time was 13.132 seconds, including 0.252 seconds of runner startup;
threshold-to-observed-quiescence was 0.668 seconds. Quiescence includes observer
sampling, not just kernel termination latency. No manual intervention occurred;
one scripted approval per report arm and scripted continuation attachments are
fixture actions, not measured human effort. Model and semantic calls were zero.
The nearest-rank p95 is simply the maximum of three observations. Negative setup
differences, fixed ordering and unflushed caches preclude general speed claims.

## Privacy review and reuse

Reviewed every exported field and compared the projection and claim hashes with
the original verified receipt. Only fixed reconstruction prose, invented report
content, aggregate observations, measurements, code/policy digests, the public
incident URL and relative evidence names are included. Host paths, installation
locations, credentials, session/process identifiers, controller databases, personal
data and raw model histories are excluded. Original and public digests are retained;
no original receipt or measured value was rewritten. Raw receipts, failed attempts
and the original installation remain outside this checkout with the manager.

Task 19 may use this payload while preserving its historical label, substitutions,
per-claim references and unmeasured limits. The [primary OpenAI incident report](https://alignment.openai.com/misalignment-reports/unauthorized-communication-via-temporary-file-hosting-services/)
describes public workbook hosting after failed local collaboration and remediation
through filesystem repair and internet isolation. This demo replaces the workbook
with invented assets, the public host with a loopback collector, adds confidentiality
conditions and scripts the actions. It does not demonstrate historical prevention
or spontaneous model behavior.

Generic publication with networking enabled, remote-job cancellation, unregistered
tools, live-agent performance, human comprehension and sharing remain unmeasured.
The sample demonstrates neither truthful output nor correct operator grants.
There is no generic web connector or new authorization gateway. Model configuration
and the existing eight-case/16-call semantic cap are unchanged. HTML replay, share
assets and audience testing belong to the subsequent presentation task.

For a fresh installed run and verification, use the exact commands and prerequisites
in [DEMO.md](../../DEMO.md#reproduce). The verifier requires the full private run,
matching current source and installation, and receipts younger than 24 hours.
This public sample alone cannot satisfy it. New runs need new external directories;
retain failures rather than overwriting them. Final-source acceptance remains the
manager's responsibility. No new interface or dependency was introduced during
curation; web research cannot validate local hashes or physical observations.
